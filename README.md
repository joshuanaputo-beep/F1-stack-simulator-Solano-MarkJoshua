## Activity Description

This activity explores a web-based stack simulator using HTML, CSS, Bootstrap, JavaScript, and jQuery. It demonstrates the Last In, First Out (LIFO) principle and introduces stack operations such as Push, Pop, Peek, and Clear.

## Starter Files

- `index.html` — HTML structure of the simulator
- `style.css` — Styling for the simulator
- `stack.js` — JavaScript implementation of the stack
